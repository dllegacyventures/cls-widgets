Claude ins Terminal.

Das Terminal ist der Ort, wo Jarvis lebt. In 5 Schritten läuft Claude Code auf deinem Rechner — jeden Befehl kannst du direkt kopieren. Hak ab, was erledigt ist: dein Fortschritt wird gespeichert.

0 / 5
01Terminal öffnen
Drück ⌘ + Leertaste, tipp Terminal, drück Enter. Das schwarze Fenster ist ab jetzt dein Cockpit.
02Homebrew installieren
Homebrew ist der App-Store fürs Terminal — damit installierst du alles Weitere mit einem Befehl.
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Wichtig: Das Terminal fragt nach deinem Mac-Passwort. Beim Tippen siehst du nichts — das ist normal. Tippen, Enter, fertig.
03Node.js installieren
Node ist die Laufzeitumgebung, die Claude Code braucht.
brew install node
04Claude Code installieren
npm install -g @anthropic-ai/claude-code
05Starten & einloggen
Einmal claude tippen — beim ersten Start öffnet sich der Login im Browser. Danach bist du drin.
claude
Test bestanden, wenn: du im Terminal ein Eingabefeld von Claude siehst. Schreib als Erstes: „Bau mir eine Test-Webseite als eine HTML-Datei."
01PowerShell öffnen
Windows-Taste drücken, PowerShell tippen, als Administrator ausführen (Rechtsklick).
02Node.js installieren
winget install OpenJS.NodeJS.LTS
Danach: PowerShell einmal schließen und neu öffnen, damit der Befehl npm gefunden wird.
03Claude Code installieren
npm install -g @anthropic-ai/claude-code
04Starten & einloggen
claude
Beim ersten Start öffnet sich der Login im Browser. Einloggen — fertig.
05Erster Test
Schreib in Claude: „Bau mir eine Test-Webseite als eine HTML-Datei." Öffne die Datei per Doppelklick. Wenn du eine Webseite siehst: Setup steht.

Wenn etwas klemmt

„command not found: brew"
Terminal komplett schließen und neu öffnen. Wenn es bleibt: Homebrew hat dir am Ende der Installation 2 Befehle angezeigt („Next steps") — die musst du einmal ausführen. Scroll im Terminal hoch und kopiere sie.
„command not found: claude" oder „npm nicht gefunden"
Terminal/PowerShell neu starten. Prüf danach mit node --version, ob Node installiert ist. Wenn nein: Schritt Node wiederholen.
Login-Fenster öffnet sich nicht
Im Terminal wird ein Link angezeigt — kopiere ihn manuell in deinen Browser und logge dich dort ein.
Ich habe keinen Claude-Account
Auf claude.ai registrieren (der Pro-Plan reicht für den Start). Mit diesem Account loggst du dich im Terminal ein.
